# Uptime bot

Uptime bot - сервис на Python для мониторинга доступности веб-приложений.
Разработан в рамках подготовки к позиции SRE/DevOps Engineer.

## Стек технологий
**Разработка и логика приложения:**
* **Язык:** Python 3.14
* **Библиотеки:** 'requests', 'python-dotenv'
* **Интеграция:** Telegram Bot API

**Инфраструктура и развертывание:**
* **Контейнеризация:** Docker/Docker Compose
* **Сети:** внутренняя сеть Docker

**Мониторинг и наблюдаемость:**
* **Сбор метрик:** Prometheus
* **Клиентская библиотека:** 'prometheus_client'
* **Визуализация:** Grafana

## Принцип работы
1. Бот отправляет HTTP GET запросы по заданному списку URL с заданным интервалом.
2. Бот проверяет код ответа сервиса и фиксирует падение по заданному таймауту или коду ошибки.
3. При изменении состояния сервиса бот уведомляет в telegram.
4. Бот ведет подсчет успешных и неуспешных проверок для расчета Uptime.
5. Бот собирает метрики при помощи Prometheus и визуализирует ввиде графика в Grafana по принципу мониторинга RED: количество успешных проверок и проверок с ошибкой + время ответа целевого URL

## Кроссплатформенность и требования
### Windows
1. Установите [Docker Desktop для Windows]
2. Включите Windows Subsystem for Linux (WSL 2)
3. Убедитесь, что папка с проектом находится в директории, к которой Docker будет иметь доступ (пример: 'C:/Users/ВашПользователь/Projects')

### macOS
1. Установите [Docker Desktop для macOS]
2. Docker Desctop автоматически эмулирует архитектуру 'amd64', если в образе не указана поддержка 'arm64'. Проект протестирован на обоих версиях

### Linux
1. Установите Docker Engine и плагин Docker Compose

### Общие требования
1. **Git** для клонирования репозитория
2. **Свободные порты:** '8080', '8000', '9090', '3000' на хост-машине

## Запуск проекта локально
1. Клонируйте репозиторий
```
bash
git clone https://github.com/ab98cd45-netizen/uptime-bot.git
cd uptime-bot
```
2. Создайте .env файл на основе .env.example и заполните его
```
bash
cp .env.example .env
```
Отредактируйте .env, указав токен вашего бота от @BotFather и ваш chat_id

3. Запустите бота через Docker Compose
```
bash
docker-compose up -d --build
```

## Доступные сервисы и сетевое взаимодействие
* **Test Nginx:** 'http://localhost:8080' - веб-сервер для тестирования работы мониторинга
* **Uptime Bot Metrics** 'http://localhost:8000' - сервер сбора собираемых метрик
* **Prometheus:** 'http://localhost:9090' - веб-интерфейс для сбора и проверки метрик
* **Grafana:** 'http://localhost:3000' - веб-интерфейс для визуализации данных

## Добавление готового дашборда в Grafana
1. Войдите в Grafana по вышеуказанному адресу, введите логин и пароль - admin/admin
2. В левом боковом меню выберите Dashboards, в открывшемся интерфейсе нажимте **New** и выберите **Import**
3. В файловой системе выберите файл uptime-dashboard.json, находяшийся в grafana/dashboards
4. В открывшемся окне прокрутите вниз до поля **Data source** и выберите **Prometheus** из списка, после чего нажмите **Import**
